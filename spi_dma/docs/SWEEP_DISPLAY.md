## 当前实现

- `host/sweep_plot.py` 替换原本滚动、单通道截顶的 QPainter 绘图，使用同一 Matplotlib 后端及参考几何。
- 每通道保留一页 float32 µV 数据，页长由采样率和时间档决定；最高 16000 SPS/15 秒时，八通道缓存约 7.68 MB，另有约 0.24 MB 边界标记。缓存不会随运行时长增长。
- USB 原始 27 字节帧仍在独立进程接收和存储。显示进程根据每包 PGA 增益解码，显示设置不发采集命令。
- 位置由序号增量及 `nominal_rate*mclk/2048000` 决定，采集时间戳检查时间一致性；不按 USB 到达时刻或 GUI tick 推进。
- 序号缺口在对应扫描位置写入 NaN，随后继续推进；不跨缺口连线。缺口超过一整页时，整页过期，清除是有意义的过期处理。
- START 新代次/重新连接保留现有画面和扫描位置，同时插入断线边界。采样率改变会重新分配时间页；修改时间档依参考实现清页。STOP 保留最后画面。
- 普通重绘、窗口缩放、显示量程改变会从缓存恢复旧页，且可重新缩放停止后的历史；不会把残留像素当作唯一数据来源。
- 视图密度过高时，每个像素列保留首点、最小值、最大值、末点，按原时间顺序绘制，并保留 NaN 分段；不再简单跳点。跨通道波形只在 axes 外裁剪。

## 明确的差异与限制

1. 参考含多模态设备、选通道、触发标记和滤波。当前只提供八通道 ADS1299 EEG 视图、时间/量程/聚焦交互；不加入没有 USB 协议字段支持的触发标记，也不恢复原项目的设备功能。
2. 参考信号在 `canvas.update_data` 中先经过滤波；当前显示原始信号，未默认施加参考的 1–30 Hz/50 Hz 滤波。实际波形形状因此可能不同，显示面板明确标注“无滤波”。
3. 参考设置使用弹窗确认；当前将相同时间/量程档位直接放在窗口底部，立即生效。默认值一致。
4. 参考以 10 ms tick 加采样数量阈值绘制；当前保留 USB 已验证的 20 Hz 显示批次和 33 ms GUI tick。只降低屏幕刷新频率，不减少原始接收数据。短暂显示积压可造成显示丢弃，单独计数。
5. 参考主要保留栅格像素，缩放/暴露窗口时可能重绘不完整；当前保留一页真实显示数据并重建画面。停止时调量程立即生效，双击聚焦保留整页，不复制原实现的重绘缺陷。
6. 网格在新覆盖条带中恢复；跨多个刻度的积压批次会恢复涉及的全部刻度，参考只恢复最后到达的刻度。
7. 峰值保留绘制可使密集高频信号呈包络；原始记录及序号统计完全不变。µV 基于标称参考，无硬件校准承诺。

## 启动与操作

在 spi_dma 根目录：

```powershell
./build/gui-venv/Scripts/python.exe -m pip install -r host/requirements-usb.txt
./build/gui-venv/Scripts/python.exe host/usb_gui.py
```

连接 COM11 后点击开始。默认 5s/100 µV；内部测试增益 1 可先选 3 mV 观察，选更小量程可看到跨通道延伸。时间档改变清页；量程改变保留历史并重新缩放；双击左侧 CH 标签聚焦，再双击恢复。

使用另一 Python 环境（例如 host/.venv）启动时，也需在该环境安装更新后的 requirements。无需重新烧录。

复测命令（独占 COM11，先断开其他软件）：

```powershell
./build/gui-venv/Scripts/python.exe -m unittest discover -s tests -p 'test_usb_*.py' -v
./build/gui-venv/Scripts/python.exe tests/render_sweep_comparison.py
./build/gui-venv/Scripts/python.exe tests/validate_sweep_hardware.py --port COM11 --seconds 60
```
# 2026-09-16：修复相邻刷新批次的假断线

`Plot.flush()` 原先只绘制 `[a,b)`，遗漏上一批末样本 `a-1` 到本批首样本 `a` 的线段。参考 `signalMat.py` 的增量绘制也存在此遗漏。250 SPS、1 秒页、约 1125 像素绘图区下，遗漏段约 4.5 像素；量程和增益影响其可见程度，不是该缺陷的根因。
